03 / Office 03 / دفتر

Office: set up once, then use it every day.

دفتر: ایک بار سیٹ کریں، پھر روزانہ استعمال کریں۔

This is the control centre. Follow the first-week list. After that, open the dashboard each morning.

یہ پورا ادارہ یہاں سے چلتا ہے۔ پہلے ہفتے والی فہرست پوری کریں۔ اس کے بعد ہر صبح ڈیش بورڈ کھولیں۔

Admin

First-week checklist

Tick these off on this computer. The ticks stay here until you clear them.

Same order, in the menus

  1. 1
    Campus / BranchInstitute → Campus / Branch → Add. Name, address, contact, logo. Save.
  2. 2
    ClassesInstitute → Classes. Add names only, such as Grade 8. Do not attach batches here — classes stay a separate list.
  3. 3
    BatchesInstitute → Batches. Add names only, such as Morning or Weekend. Do not attach a class or subjects here — batches stay a separate list.
  4. 4
    SubjectsInstitute → Subjects. Add course names only, such as Physics. Do not attach them to a batch here — subjects stay a separate list.
  5. 5
    Fee PlansInstitute → Fee Plans. Name and amount. You attach these when enrolling a student.
  6. 6
    Teachers, then studentsThis is where the lists join. People → Add Teacher, then Enrol Student. For each person: pick the batches, then pick subjects for each of those batches. Create logins so they can sign in.
  7. 7
    Zoom (if you use live class)Profile menu → Manage Zoom API, then Online Lectures → Master Meeting.
  8. 8
    Lectures and challansCreate one lecture and one fee bill to confirm everything works.
How class, batch and subject connectThey are three independent lists. Nothing is linked under Institute. The link is made on the person: when you add or edit a student or a teacher, you select the batch (or several batches), then select subjects against each of those batches.

Enrol a student

People → Enrol Student, or Enrol Student on the Main Dashboard.

  1. 1
    Personal detailsStudent Name (required), Father Name, CNIC, date of birth, gender.
  2. 2
    Class (optional label)Choose a class such as Grade 9 if you use classes. This does not attach batches. Class, batch and subject are still separate lists.
  3. 3
    Select batchesTick every batch this student belongs to, such as Morning and Weekend. Student code is usually filled for you.
  4. 4
    Subjects against each batchFor every batch you ticked, pick the subjects for that batch (Subjects per Batch). That is how batch and subject are linked — on this student, not in Institute.
  5. 5
    Fee plansSelect plans. Add a discount if needed. Check Monthly Fee in the summary.
  6. 6
    ContactPhones, address, city. Keep the record Active.
  7. 7
    LoginsGuardian email and password for the parent portal. Student email and password for the student portal. Zoom email only if your institute uses it.
  8. 8
    SaveCheck spelling, phones, class, batches, subjects per batch, and fee plan before you save. Edit Student later if you need to change batches or subjects.

Add or edit a teacher (same linking)

People → Add Teacher (or Edit Teacher). After the name and login, select the teacher’s batches, then Assign Subjects per Batch — pick subjects against each batch. Saving the teacher is what links that teacher to those batches and subjects. Edit the teacher later if the mapping should change.

Many students at once

People → Bulk Upload. Download the Excel template. Do not change column headings. One student per row. Upload, then fix any error rows. Try a small file first.

Portal Access

People → Portal Access. Use this if a student should not enter the student portal (for example unpaid fees). You can turn automatic blocking of defaulters on or off, or exempt a student. The student sees a blocked message until you restore access.

Schedule a lecture

Online Lectures → Add Lecture, or New Lecture on the dashboard.

  1. 1
    Title, date, time, durationUse a clear title students will recognise.
  2. 2
    Teacher, batch, subjectsChoose the teacher first. Then pick a batch and the subjects for that lecture (from the batches and subjects already assigned to that teacher).
  3. 3
    How the class is heldZoom API (needs Zoom + Master Meeting), Manual Link (paste Zoom / Meet / Teams), or In-Person.
  4. 4
    SaveFor a weekly timetable, use Recurring Schedules instead of adding each day by hand.

Lectures Dashboard (or Live Lecture Monitor) shows live and upcoming classes. Open a lecture to Start as Host, open the whiteboard, or Take Manual Attendance.

Fees

  1. 1
    Generate ChallanFinance → Generate Challan. Pick students, month, due date. Generate. Print if needed.
  2. 2
    Process PaymentWhen cash or a transfer arrives at the office: find the challan, enter amount, date and method, then save.
  3. 3
    Receipt InboxParents upload photos from Fee Pay. Check the photo, then Approve or Reject. You can add a short message for the parent. Optional: turn on automatic approval.
  4. 4
    ReportsDaily, Monthly, Yearly collection, and Fee Defaulters. Set the period, then Print or Export. Always say the date range when you share a report.

Profile menu → Select Currency so amounts show the correct symbol.

Salary, approvals, account

Teacher Salary: create Salary Plans → assign to teachers → run Payroll → check advances → mark Payment Status → print Salary Reports.

Approvals: a number on the menu means homework, lesson plans, teacher reports, student leave or teacher leave is waiting. Open the item, read it, then Approve or Reject with a short comment.

Your account menu: Switch Account (if you also teach), Default Portal, Account Settings, Toolbar Settings, Manage Users, Manage Permissions, Manage Zoom API, Google Drive, Appearance (Light / Dark / Auto), Sign Out.

Switch Account: if your login is both office and teacher, use Switch Account in the profile menu. You land in the other portal without signing in again.

Create a lecture

Create Lecture. Title, date, time, duration, batch and subjects. Then choose Zoom API, Manual Link, or In-Person. If Zoom is not set up, the page tells you to use Manual Link or In-Person. Use Schedule Recurring for a weekly timetable. Schedule shows your calendar.

Planning, homework, assignments, quizzes

Lesson Plans

Planning → Lesson Plans. Write the plan, attach files, submit. Students see it after office approval if your institute requires it.

Homework

New Homework: title, instructions, subject, batch (or specific students), due date, optional worksheet. Students submit from their portal. Open submissions to review.

Daily report

Submit Report after teaching. Office approves it under Report Approval.

Assignments

Longer work than daily homework. Create it, students submit, then grade and write feedback.

Quizzes & Exams

  1. 1
    Saved questionsKeep a bank you can reuse.
  2. 2
    New quizClass, subject, time limit, instructions. Multiple choice can be marked automatically. Short answers you mark yourself.
  3. 3
    Send to studentsWhen status is Live now, students can start it. Close it when finished.

Students, leave, salary, files

Documents — upload notes and PDFs. Students see them in My Documents. Use clear names such as Grade8-Math-Chapter3.pdf.

My Students — learners in your batches.

Apply Leave — dates and reason, then Submit. Wait until status is Approved. Do not assume it is approved while it is Pending.

My Salary — your pay slips. Questions about amounts go to the office.

Admins who also teach can Switch Account back to the office portal.

09 / Help 09 / مدد

If something does not work.

اگر کچھ کام نہ کرے۔

ProblemWhat to try
Cannot sign inCheck email spelling and Caps Lock. Use the correct portal email (student vs parent vs teacher). Ask admin to reset the password.
A menu is missingYou may not have permission, or the institute hid that tool.
Form will not saveFill required fields. Fix red messages. Check dates and amounts.
Cannot find a recordClear filters. Try a shorter search. Check class or batch. Go to the next page.
Student portal blockedOffice: People → Portal Access. Fees may be overdue, or the account was suspended.
Cannot join classConfirm date and time. Teacher must start. Allow pop-ups. Try Join from the lecture details page.
Waiting for HostWait for the teacher to tap Start Class Now.
Receipt still SubmittedThe office has not processed it yet. Message the office if it is overdue.
Google sign-in does nothingThe institute has not connected Google yet. Use email and password.
Page frozenRefresh, sign out and in, or try another browser.
